# Вища чи нижча?

Готова статична версія гри. Усі основні дані (профіль, статистика, налаштування та незавершена гра) зберігаються у браузері через `localStorage`.

## Файли

- `index.html` — сторінка сайту
- `style.css` — дизайн та адаптивність
- `game.js` — логіка гри
- `manifest.webmanifest` — опис PWA, щоб сайт можна було встановити як застосунок
- `sw.js` — кешування для роботи після першого завантаження
- `icon.svg` — іконка

## Запуск на комп'ютері

Для швидкої перевірки можна відкрити `index.html` у браузері. Для PWA/service worker краще запускати через локальний HTTP-сервер.

Наприклад, у папці сайту:

```bash
python -m http.server 8000
```

Потім відкрити `http://localhost:8000`.

## Публікація як справжнього сайту

Це статичний сайт: серверна база даних не потрібна. Папку можна завантажити на GitHub Pages, Netlify, Vercel або інший static hosting. Після публікації сервіс дасть постійне посилання виду `https://...`, за яким у гру можна заходити з телефону чи ПК.
